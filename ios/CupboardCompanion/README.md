# Cupboard Companion iOS

Native SwiftUI iPhone wrapper for the Cupboard Companion standalone web app.

Open `CupboardCompanion.xcodeproj` in Xcode, select an Apple developer team, and run on an iPhone or simulator. The app loads:

`https://cosmicbubblegumgirl.github.io/vercel-apps-github-pages/cupboard-companion/`

The web app includes its own login and IndexedDB storage, so grocery data persists inside the iOS WebView.
